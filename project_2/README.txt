Description
---------------------------------------------------------------------------------------
Given two lists of n labels 0, 1, …, n-1, suppose these lists are generated by inorder 
and postorder traversals of a binary tree. 
Design an algorithm to construct the binary tree from these two lists. Your algorithm 
should also identify inputs for which the problem has no solution.

The problem can be solved by a recursive algorithm based on the following observation:
There exists a binary tree with inorder traversal list: i0, i1, …, in-1 and postorder
traversal list p0, p1, …, pn-1 if and only if pn−1 = ik (the root’s label), the sets
formed by the first k labels in both lists are the same: { i0, i1, …, ik-1 } = { p0, 
p1, …, pk-1 } (the labels of the nodes in the left subtree) and the sets formed by the 
other n-k-1 labels excluding the root are the same: { ik+1, ik+2, …, in-1  } = { pk, 
pk+1, …, pn-2 } (the labels of the nodes in the right subtree).

---------------------------------------------------------------------------------------
Requirements
---------------------------------------------------------------------------------------
1. Design an algorithm to construct the binary tree from two given lists of labels,
which are supposed to be generated by inorder and postorder traversals of the tree.
2. Implement your algorithm using your preferred language.
3. Design a suite of test cases, including at least the following cases: the binary 
tree is empty; the problem has no solution; n = 20; n = 50; n =100; n = 200.
4. Run your program with each of test cases. Present the result of each run.
5. Analyze the time efficiency of the algorithm in big-notation and compare your 
analysis with your tests.
